# Seasonal-Agriculture-Performance-Insights
Beyond Seasonal Averages: A Risk & Archetype-Driven Analysis of Agricultural Performance

A data analytics project that goes beyond "average yield by season" to answer sharper, decision-relevant questions about seasonal agricultural performance — using a composite performance index, unsupervised clustering, season-specific driver analysis, risk-adjusted profitability, decile benchmarking, and multivariate anomaly detection.
